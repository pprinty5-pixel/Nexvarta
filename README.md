# Nexvarta 🚀

Automated Next.js production portal with CI/CD deployment on Hostinger VPS.

## Features
- **Next.js 15 App Router**
- **Production Process Management** via PM2 (`ecosystem.config.cjs`)
- **Automated GitHub Actions CI/CD** (`.github/workflows/deploy.yml`)
- **Hostinger KVM 1** AlmaLinux 9 environment with Swap memory support
- **Digital News & Media Platform**
